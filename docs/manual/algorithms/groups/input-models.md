# Data Loading and Input Models

**English** · <a href="../../../../zh/manual/algorithms/groups/input-models.html">简体中文</a>

This category covers the input prerequisites of algorithms: loading classical data, Boolean truth tables, and operators into oracles, block encodings, and quantum data structures. Most entries come from the `oracq.algorithms.input_model` subpackage (`prepare-select` comes from `common`); before using any estimation, solving, or simulation algorithm, an appropriate access model usually needs to be selected and constructed here first.
