# Algorithm catalog

The per-algorithm manual pages — interface, implementation notes, validation
approach, and known gaps for each of the 60+ algorithms in the library — are
currently written in Chinese only while their English translations are in
progress. Browse the
[Chinese algorithm catalog](../../zh/manual/algorithms/index.html); the
English API reference for every module is already available under
[API reference / Algorithms](../../api/algorithms/index.rst).

The table below lists the categories with representative pages (Chinese):

- Query and search: [Grover](../../zh/manual/algorithms/grover.html), [QAE](../../zh/manual/algorithms/qae.html), [quantum counting](../../zh/manual/algorithms/quantum-counting.html)
- Basic query algorithms: [Deutsch–Jozsa](../../zh/manual/algorithms/deutsch-jozsa.html), [Simon](../../zh/manual/algorithms/simon.html), [Bernstein–Vazirani](../../zh/manual/algorithms/bernstein-vazirani.html)
- Fourier and arithmetic: [QFT](../../zh/manual/algorithms/qft.html), [Fourier addition](../../zh/manual/algorithms/fourier-addition.html), [order finding](../../zh/manual/algorithms/order-finding.html)
- Hamiltonian evolution: [Trotter](../../zh/manual/algorithms/trotter.html), [QSP phase synthesis](../../zh/manual/algorithms/qsp-phase-synthesis.html), [QSVT HamSim](../../zh/manual/algorithms/qsvt-hamiltonian-simulation.html)
- Estimation and testing: [QPE](../../zh/manual/algorithms/qpe.html), [Hadamard test](../../zh/manual/algorithms/hadamard-test.html), [Swap test](../../zh/manual/algorithms/swap-test.html)
- Quantum linear systems: [Costa walk](../../zh/manual/algorithms/costa-walk.html), [CKS](../../zh/manual/algorithms/cks.html), [VTAA-CKS](../../zh/manual/algorithms/vtaa-cks.html)
- QODE / QPDE: [Schrödingerization](../../zh/manual/algorithms/schrodingerization.html), [LCHS](../../zh/manual/algorithms/lchs.html), [Carleman](../../zh/manual/algorithms/carleman.html)
- Variational and optimization: [VQE](../../zh/manual/algorithms/vqe.html), [QAOA MaxCut](../../zh/manual/algorithms/qaoa-maxcut.html), [DQI](../../zh/manual/algorithms/dqi.html)
- Quantum walks: [coined walk](../../zh/manual/algorithms/coined-cycle-walk.html), [Szegedy](../../zh/manual/algorithms/szegedy-walk.html), [MNRS](../../zh/manual/algorithms/mnrs-search.html)
- Quantum machine learning: [QPCA](../../zh/manual/algorithms/qpca.html), [QCNN](../../zh/manual/algorithms/qcnn.html)
- Data loading and input models: [state preparation](../../zh/manual/algorithms/state-preparation.html), [XOR database](../../zh/manual/algorithms/xor-database.html), [Select-Swap QROM](../../zh/manual/algorithms/select-swap.html)
- Quantum error correction: [repetition codes](../../zh/manual/algorithms/repetition-codes.html)
