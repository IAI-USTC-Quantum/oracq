# Algorithm catalog

The per-algorithm manual pages — interface, implementation notes, validation
approach, and known gaps for each of the 60+ algorithms in the library — are
currently written in Chinese only while their English translations are in
progress. Browse the
<a href="../../../zh/manual/algorithms/index.html">Chinese algorithm catalog</a>; the
English API reference for every module is already available under
[API reference / Algorithms](../../api/algorithms/index.rst).

The table below lists the categories with representative pages (Chinese):

- Query and search: <a href="../../../zh/manual/algorithms/grover.html">Grover</a>, <a href="../../../zh/manual/algorithms/qae.html">QAE</a>, <a href="../../../zh/manual/algorithms/quantum-counting.html">quantum counting</a>

- Hamiltonian evolution: <a href="../../../zh/manual/algorithms/trotter.html">Trotter</a>, <a href="../../../zh/manual/algorithms/qsp-phase-synthesis.html">QSP phase synthesis</a>, <a href="../../../zh/manual/algorithms/qsvt-hamiltonian-simulation.html">QSVT HamSim</a>
- Estimation and testing: <a href="../../../zh/manual/algorithms/qpe.html">QPE</a>, <a href="../../../zh/manual/algorithms/hadamard-test.html">Hadamard test</a>, <a href="../../../zh/manual/algorithms/swap-test.html">Swap test</a>
