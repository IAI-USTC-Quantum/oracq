\begin{abstract}
Quantum scientific-computing algorithms are expressed through access
models whose concrete implementations can substantially change their
numerical behavior and resource requirements.
Here, we present \pqlang{}, a Python framework for quantum algorithm researchers
implementing, composing, and comparing these algorithms.
An embedded interface generates a modular register-level intermediate
representation (RIR) that preserves calls, static repetition, control,
adjoint, and declared but unimplemented oracle modules.
Stored open programs can be restored and partially bound to compatible
implementations, with explicit resource capture and binding diagnostics.
Role views and algorithm contracts connect host-side inputs to program
generation without serializing Python callbacks.
QRAM access, reversible finite-precision arithmetic, and a compiler for
supported numerical functions provide implementations of scientific
access models.
Open-program analysis separates known circuit costs from unresolved
oracle calls; after binding, the same module structure supports logical
gate counts and per-resource QRAM access accounting.
A controlled study compares gate-table, QRAM-table, and arithmetic
realizations of one open algorithm, while differential-equation and
fluid-dynamics examples exercise deeper compositions.
Numerical witnesses and native-backend comparisons are reported with
their instance scope, reference semantics, and remaining assumptions.
The contribution is an extensible implementation and analysis workflow
connecting abstract quantum algorithms to concrete scientific-computing
oracles; general convergence guarantees and physical hardware cost models
remain outside the present scope.
\end{abstract}
